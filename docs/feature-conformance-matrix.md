# read-pal 功能清单与验收规范（Conformance Matrix）

依据：PRODUCT.md（产品目标）、DESIGN.md（视觉规范）、全部路由/页面、28 个后端 router。
测试环境：本地 dev（backend :8000 + web :3000），demo 用户 + 真实上传书籍《路边野餐》。
每项功能：预期行为（Expected）→ 验收标准（Criteria）→ 实测结果（Result: PASS/FAIL/PARTIAL + 证据）。

---

## A. 认证与账户（auth/password_reset/account）

| # | 功能 | 预期行为 | 验收标准 |
|---|------|---------|---------|
| A1 | 注册 | 邮箱+密码创建账户，返回 token | 201；重复邮箱 409；弱密码 422 |
| A2 | 登录 | 校验凭据，发 access+refresh token | 200 + token；错密码 401；10次/分钟限流 429 |
| A3 | 登出 | 清除客户端 token | UI 跳转 landing；受保护页跳 auth |
| A4 | 忘记密码 | 发重置链接（无 SMTP 时 console 打印 token） | 200；token 出现在日志 |
| A5 | 重置密码 | token 有效，新密码生效 | 200；新密码可登录；旧密码 401 |
| A6 | 账户删除 | 密码确认后删除账户+级联数据 | 204；登录变 401；确认弹窗要求密码 |
| A7 | 会话保持 | token 过期后 refresh 自动续期 | 401 → refresh → 重放成功 |
